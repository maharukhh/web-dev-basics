# Color Palette Generator

A random color palette generator with lockable swatches and one-click hex code copying.

## Features
- Generates 5 random hex colors at once
- Click any swatch to copy its hex code to the clipboard (with a "Copied!" confirmation)
- Lock individual swatches to keep them while regenerating the rest
- Press **Spacebar** as a shortcut to generate a new palette
- Automatic text contrast (dark or light label) based on each swatch's brightness


## How It Works
- Each color is generated by picking 6 random hex digits (`0-9`, `A-F`).
- Locking a swatch stores its index in a `locked` array — when generating a new palette, locked swatches are skipped and keep their existing color.
- Text/label contrast is calculated using a relative luminance formula on each color's RGB values, so labels stay readable on both light and dark swatches.
- Copying uses the browser's `navigator.clipboard` API.

## Tech Used
- Plain HTML, CSS, and JavaScript (no frameworks)
- Clipboard API
- Google Fonts (Space Grotesk)

## Key Concepts Practiced
- Dynamic styling (colors generated and applied at runtime)
- Clipboard API
- Basic color theory (luminance/contrast calculation)

## Possible Improvements
- Export palette as a CSS variables file or Adobe/Figma-compatible format
- Generate palettes based on color harmony rules (complementary, analogous, etc.) instead of pure randomness
- Save favorite palettes to a gallery

## Known Limitations
- Colors are fully random, so palettes aren't guaranteed to be aesthetically harmonious
- Clipboard copying requires a browser that supports the Clipboard API (all modern browsers do)
